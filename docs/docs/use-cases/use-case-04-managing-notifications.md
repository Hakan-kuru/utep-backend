# Use Case 04 — Bildirimlerin Yönetilmesi

## 1. Amaç

Kullanıcıların etkinlik ve başvuru durumlarıyla ilgili bilgilendirilmesini sağlamak.

## 2. Aktörler

**Primary:** Öğrenci, Kulüp Yöneticisi

**Secondary:** Sistem

## 3. MVP Durumu

Bu use case MVP kapsamında uygulanmayacaktır.

Bildirimler, kullanıcı deneyimini geliştiren bir özellik olmakla birlikte sistemin temel işleyişi için zorunlu değildir.

Öğrenci ve kulüp yöneticisi, bildirimler olmadan da etkinlik oluşturma, başvurma, başvuruları yönetme ve katılım işlemlerini gerçekleştirebilir.

Bu nedenle bildirim sistemi **V2'ye bırakılmıştır**.

## 4. Gelecekteki Kapsam

V2 kapsamında başvuru durumu, etkinlik değişiklikleri ve benzeri önemli durumlar için kullanıcılara bildirim gönderilmesi planlanmaktadır.

Bildirimlerin hangi kanallardan gönderileceği V2 geliştirme sürecinde belirlenecektir.

## 5. Neden Sonraya Bırakıldı?

Bildirim sistemi temel MVP işleyişini etkilemediği için ilk sürümden çıkarılmıştır.

Temel sistem çalışır hâle geldikten sonra bildirim özelliği ayrıca eklenebilir.
